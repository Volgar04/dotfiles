# My dotfiles & stuffs

This is all my dotfiles and stuffs I'd like to keep between my machines. I manage my dotfiles with [stow](https://www.gnu.org/software/stow/).

## Requirements

- Terminal: [iTerm](https://iterm2.com/)
- Dependency manager: [brew](https://brew.sh/)
- Window manager: [yabai](https://github.com/koekeishiya/yabai)
- Shell: [oh-my-zsh](https://ohmyz.sh/)
- Editor: Neovim
